# スケール

スマホ向けの放置・インクリメンタルゲーム。HTML と JavaScript だけで動き、ビルドツールや依存パッケージは不要。

ミクロからマクロ、そして抽象へ。リセットのたびに舞台のスケールが一段変わっていく。

| 章 | 舞台 | リセット | 状態 |
| --- | --- | --- | --- |
| 第 1 章 | 細胞 | 進化 → 遺伝子 | 実装済み |
| 第 2 章 | 宇宙 | ビッグバン | 未実装 |
| 第 3 章 | 数学 | 公理の書き換え | 未実装 |

## 第 1 章：細胞

- エネルギーで「分子」を買うと、分子がエネルギーを生む
- 細胞は分子を、組織は細胞を……と、上の段が 1 つ下の段を自動で増やす（全 7 段）
- 同じ段を 25・50・以降 100 個ごとに買うと「適応」し、その段の生産が ×3
- エネルギー 1e15 で「進化」できる。全部リセットする代わりに遺伝子が手に入る
- 遺伝子は累計数に応じて全生産を強化し、さらに永続強化（自動購入など）に使える

## ディレクトリ構成

```
.
├── index.html            # 画面の骨組み
├── style.css             # 見た目（スマホ縦画面向け）
├── manifest.webmanifest  # ホーム画面に追加したときの設定（全画面・縦向き）
├── src/
│   ├── main.js           # 起動・ゲームループ・セーブ・オフライン進行
│   ├── ui.js             # 画面の組み立てと更新、操作の受け付け
│   ├── logic.js          # ゲームのルール（画面に依存しない）
│   ├── data.js           # 数値設計（バランス調整はここ）
│   └── big.js            # 巨大な数（1e308 超）を扱う数値クラスと表示
├── tools/
│   ├── sim.js            # バランス確認用シミュレーション
│   └── test.js           # 数値処理とロジックのテスト
├── assets/icons/         # ホーム画面用アイコン
└── docs/                 # 設計・仕様ドキュメント
```

## 開発

ES モジュールを使っているため、`index.html` を直接開くのではなくローカルサーバー経由で開く。

```sh
python3 -m http.server 8000   # または npm run serve
```

ブラウザで http://localhost:8000 を開く。

### テストとバランス確認（Node.js が必要）

```sh
npm test          # 数値処理とロジックのテスト
npm run sim -- 10 # 「上の段から買えるだけ買う」プレイで 10 回進化するまでの経過を表示
```

数値を変えたら `npm run sim` で、各段の解放時間や進化までの時間を確認する。

## セーブ

- ブラウザの localStorage に 10 秒ごと、およびアプリを閉じたとき・裏に回したときに自動保存
- 閉じていた間の進行は、起動時にまとめて反映（最大 24 時間）
- 設定タブの「書き出し」「読み込み」で別の端末に引き継げる

## スマホ対応

- スクロール以外のズーム・長押しメニューなどは無効化
- ボタンは長押しで連続購入
- ブラウザの「ホーム画面に追加」で、アドレスバーなしの全画面で起動できる
