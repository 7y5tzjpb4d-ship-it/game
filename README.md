## ディレクトリ構成

```
.
├── index.html            # エントリーポイント
├── style.css             # 画面レイアウト（ノッチ対応・スクロール/ズーム抑止）
├── manifest.webmanifest  # ホーム画面に追加したときの設定（全画面・縦向き）
├── src/
│   ├── main.js           # 起動処理・論理解像度の設定
│   ├── screen.js         # 画面サイズへの合わせ込み・高解像度対応
│   ├── game.js           # ゲームループ・更新・描画
│   └── input.js          # タッチ／キーボード入力
├── assets/               # 画像・音声などのアセット
│   └── icons/            # ホーム画面用アイコン
└── docs/         # 設計・仕様ドキュメント
```

## 開発

ES モジュールを使っているため、`index.html` を直接開くのではなくローカルサーバー経由で開く。

```sh
python3 -m http.server 8000
# または
npx serve .
```

ブラウザで http://localhost:8000 を開く。VS Code の場合は拡張機能「Live Server」でも可。

## スマホ対応の方針

- ゲーム内の座標は常に **480 × 640（縦長 3:4）の論理座標**で扱う。表示サイズは端末に合わせて `src/screen.js` が自動で拡大縮小する
- 高解像度画面（Retina など）でもぼやけないよう、内部解像度を端末のピクセル密度に合わせている
- スクロール・ピンチズーム・ダブルタップズーム・長押しメニューは無効化済み
- アプリを切り替えるとゲームは一時停止する
- ブラウザの「ホーム画面に追加」で、アドレスバーなしの全画面で起動できる

## スマホでの動作確認

- **同じ Wi-Fi の PC から**：PC で `python3 -m http.server 8000` を実行し、スマホのブラウザで `http://<PC の IP アドレス>:8000` を開く
- **GitHub Pages で公開**：リポジトリの Settings → Pages で公開すると、スマホから URL を開くだけで遊べる
