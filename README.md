# 数の地平

数学を舞台にした、スマホ向けの放置・インクリメンタルゲーム。HTML と JavaScript だけで動き、ビルドツールや依存パッケージは不要。

数の世界を一段ずつ広げていき、リセット（拡張）のたびに新しい仕組みが加わる。全 9 層の構想は [docs/design.md](docs/design.md) を参照。

| 層 | 舞台 | 状態 |
| --- | --- | --- |
| 1 | 自然数 | 実装済み |
| 2 | 整数 | 実装済み |
| 3〜9 | 有理数・実数・線形・微分方程式・周波数・ベクトル場・複素関数 | 構想 |

## 第 1 層：自然数

- 「数」で指を買うと、指が数を生む。刻み目は指を、小石は刻み目を……と、上の段が下の段を自動で増やす（全 7 段）
- 同じ段の購入数が高度合成数（12, 24, 36, 48, 60, 120, …）に届くたびに、その段の生産 ×2
- この周で数えた合計が 1e15 に届くと「繰り上がり」できる。リセットする代わりに「桁」が手に入る
- 桁は累計数に応じて数の生産を上げ、さらに永続強化（約数の力、素数の輝き、自動購入、記数法の進化など）に使える
- 対数を取ると「証明」（制約付きの周）に挑戦でき、完成すると定理（永続効果）が手に入る
- 桁を 1.8e308 個手元に貯めると、第 2 層へ拡張できる

## 第 2 層：整数

- 拡張すると第 1 層の進行（証明を含む）がリセットされ、通貨「整数」が手に入る
- 整数で「負の数の工場」を買うと、負のエネルギーが貯まり、第 1 層の数・桁と拡張で得られる整数が増える
- 整数の強化で、拡張後の遊び直しを速くできる（基礎の継承、自動の公理、定理の記憶、自動拡張など）
- 後半は「利息」で、所持している整数が毎秒一定の割合で増える
- 整数を 1e250 貯めると、第 3 層への入口が見える（第 3 層は準備中）

```
.
├── index.html            # 画面の骨組み

│   ├── main.js           # 起動・ゲームループ・セーブ・オフライン進行
│   ├── ui.js             # 画面の組み立てと更新、操作の受け付け
│   ├── logic.js          # ゲームのルール（画面に依存しない）
│   ├── data.js           # 数値設計（バランス調整はここ）
│   └── big.js            # 巨大な数（1e308 超）を扱う数値クラスと表示
├── tools/
│   ├── sim.js            # バランス確認用シミュレーション
│   └── test.js           # 数値処理とロジックのテスト
├── assets/icons/         # ホーム画面用アイコン
└── docs/design.md        # 設計書（全 9 層の構想と第 1 層の詳細）
```

## 開発

ES モジュールを使っているため、`index.html` を直接開くのではなくローカルサーバー経由で開く。

```sh
python3 -m http.server 8000   # または npm run serve
```

ブラウザで http://localhost:8000 を開く。

### テストとバランス確認（Node.js が必要）

```sh
npm test          # 数値処理とロジックのテスト
npm run sim       # 第 2 層への拡張に届くまでの経過を表示（-v で毎回の繰り上がりを表示）
SIM_EXPANSIONS=50 npm run sim  # 拡張を 50 回するまで続ける
```

シミュレーションは「上の段から買えるだけ買い（約数の力を取ったら節目で買い止め）、桁の獲得効率が落ち始めたら繰り上がり、桁は安い強化から使う」プレイヤーを想定している。数値を変えたら必ず確認する。

## セーブ

- ブラウザの localStorage に 10 秒ごと、およびアプリを閉じたとき・裏に回したときに自動保存
- 閉じていた間の進行は、起動時にまとめて反映（最大 24 時間）
- 設定タブの「書き出し」「読み込み」で別の端末に引き継げる

## スマホ対応

- スクロール以外のズーム・長押しメニューなどは無効化
- ボタンは長押しで連続購入
- ブラウザの「ホーム画面に追加」で、アドレスバーなしの全画面で起動できる
